# 📚 Atividade de Manipulação de Strings em Java

Este repositório contém os exercícios práticos desenvolvidos para treinar o uso de métodos nativos da classe `String` e a interação com o usuário utilizando a classe `Scanner` em Java.

---

## 🛠️ Descrição dos Exercícios

1. **Contagem de Caracteres:** 
   * Pede o nome completo do usuário e utiliza o método `.length()` para retornar o número total de caracteres (incluindo espaços).
2. **Conversão de Caixa (Case):** 
   * Solicita um nome e exibe o texto totalmente convertido para letras maiúsculas (`.toUpperCase()`) e minúsculas (`.toLowerCase()`).
3. **Extração de Caractere:** 
   * Lê um nome e utiliza o método `.charAt(0)` para extrair e exibir a primeira letra do texto.
4. **Busca em Frases:** 
   * Recebe uma frase e uma palavra, verificando a ocorrência da palavra na frase por meio do método `.contains()`, retornando um valor booleano (`true` ou `false`).
5. **Comparação de Textos:** 
   * Solicita o nome duas vezes e compara se ambos são equivalentes ignorando diferenças entre maiúsculas e minúsculas utilizando o método `.equalsIgnoreCase()`.

---

## 🚀 Tecnologias Utilizadas
* **Linguagem:** Java
* **Entrada de Dados:** `java.util.Scanner`
